Deployment

Install released tools or develop from source.

Galaxy administrators can install released GLEAM suites from the Galaxy ToolShed. Developers can clone this repository, register the wrappers in a local Galaxy tool panel, and run the existing Planemo-backed CI tests.

Exact ToolShed suite repositories:

  • suite_tabular_learner
  • suite_imagelearner
  • suite_multimodallearner
  • suite_ludwig
  • suite_tiler
  • suite_embedding_extractor
  • suite_mil_bag
